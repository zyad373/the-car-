# Car Value Prediction App

A machine learning web application built with Streamlit and a Scikit-Learn Decision Tree Regressor to predict vehicle values based on specifications like year, engine horsepower, make, vehicle size, and transmission type.

## Local Installation & Running

1. Clone or download this repository.
2. Put your trained `model.pkl` file in the project folder.
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```

## Requirements
* python >= 3.8
* streamlit
* pandas
* scikit-learn
